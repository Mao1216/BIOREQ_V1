# Sistema de Requerimiento de Materiales - DF

Aplicación web interna para digitalizar el proceso de requerimiento de materiales para desarrollo (FICHA 1 - DF).

## Estructura del Proyecto

*   **`index.html`**: Punto de entrada de la aplicación.
*   **`css/style.css`**: Estilos personalizados y animaciones.
*   **`js/db.js`**: Simulación de base de datos, constantes de listas y usuarios.
*   **`js/app.js`**: Lógica de renderizado, enrutamiento, validaciones y flujos de estado.

## Cómo ejecutar

Al ser una aplicación basada en Vanilla JS sin dependencias de backend externas (por ahora), simplemente abre el archivo `index.html` en tu navegador web.
